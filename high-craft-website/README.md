# JP ASSOCIATES W.L.L. (جي بي اسوسيتس ذ.م.م.)
## High-Craft Corporate Accounting & Advisory Website

A bespoke, production-ready website engineered for **JP ASSOCIATES W.L.L.** with an executive, cool, spacious aesthetic tailored specifically for institutional accounting, corporate tax, and management consulting.

---

## 1. Brand Color System

| Role | Color / Hex | Application |
|---|---|---|
| **Primary** | **Deep Navy (`#232766`)** | Main brand identity, primary CTA buttons, active states, key headings, structural footer |
| **Secondary Accent** | **Golden Tone (`#B18937`)** | Button hover states, subtle logo harmony, fine underline accents, highlight badges, delicate micro-markers |
| **Neutrals** | **Black (`#111827`)** | High-contrast headlines & dark canvas |
| **Neutrals** | **Cool Grey (`#4B5563`, `#64748B`)** | Body copy, descriptions, secondary metadata |
| **Backgrounds** | **Light Grey (`#F8FAFC`, `#F1F5F9`)** | Crisp, airy, spacious section surfaces |
| **Surface** | **Pure White (`#FFFFFF`)** | Elevated cards, top-bar, light header navigation |
| **Dividers** | **Hairline Border (`#E2E8F0`)** | Clean architectural card borders and section rules |

---

## 2. Typography

- **Font Family:** `Plus Jakarta Sans` ONLY (Weights: 300, 400, 500, 600, 700, 800) loaded via Google Fonts preconnect.
