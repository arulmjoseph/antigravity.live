# Image Converter Web App (Vercel Ready) 🖼️📄

A fast, client-side Web Application version of **Image Converter** built with HTML5, CSS3, JavaScript, and Canvas WebAssembly engines.

---

## Features & Active Defaults

- **Active Defaults**:
  - **Image Size / Width**: Set to **`Original Size`** by default *(as specified in design)*.
  - **File Renaming**: Set to **`Original Name`** by default *(as specified in design)*.
- **Bulk Format Export**: **WEBP ⭐**, **PDF 📄**, **JPG**, **PNG**, **BMP**, **GIF**.
- **PDF Optimization & Conversion**: Process images & PDFs in-browser with quality compression.
- **Custom Width & Proportional Scaling**: Preserves original aspect ratios.
- **Bulk SEO Keyword Slugs**: Auto-converts raw keyword lists into dash-separated SEO filenames (`cfo-financial-strategy-meeting-dubai.webp`).
- **Batch ZIP Download**: Instant client-side ZIP archive packaging powered by `JSZip`.

---

## Deploying to Vercel (100% Free)

### Option 1: GitHub Push (Recommended)
1. Push this project folder (`ImageConverterWeb`) to your GitHub repository.
2. Go to [Vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository and click **Deploy**.

### Option 2: Vercel CLI
Run from terminal inside the `ImageConverterWeb` directory:
```bash
npx vercel
```
